FilaCero - Parte 6: seguridad para producción, accesibilidad, pantalla de sala
y documentación de arquitectura (Momento Evaluativo 3)
=================================================================

1) BORRA en tu proyecto estas carpetas (para no mezclar archivos viejos):
     FilaCero\backend\app
     FilaCero\frontend-react\src
   y copia la carpeta FilaCero de este zip encima de la tuya.
   (Tu .env, tu venv, node_modules y tu test_mejoras_entrega.py no se tocan.)

2) Backend (PowerShell, carpeta backend, venv activo):
     pip install -r requirements-dev.txt     <- versiones fijas + waitress
     flask db upgrade                         <- bloqueo de cuenta y revocación
     python -m pytest                         <- 84 pruebas (77 + tus 7)
     python simulacion.py                     <- 50 verificaciones
     python simulacion.py --cargar --desde 2026-10-25 --hasta 2026-10-30
         (cuando pregunte, escribe BORRAR y Enter)

3) Prueba de carga (opcional, con el backend encendido en OTRA terminal):
     $env:RATE_LIMIT_ACTIVO="false"; python run.py
     python simulacion.py --carga --url http://127.0.0.1:5000 --usuarios 40 --segundos 20

4) Frontend: npm install (por si acaso) y npm run dev
     Pantalla de sala:  http://localhost:5173/sala
     (o desde Admin > Sedes, ícono de pantalla en cada sede)

5) Documentación para el profesor: docs\arquitectura\README.md
   Seguridad y pendientes para producción: SECURITY.md
